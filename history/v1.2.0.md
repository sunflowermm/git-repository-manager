## 🌻 向日葵Git仓库管理 v1.2.0

### 🏗️ 架构升级

- **渲染层全面迁移至 Vue 3 + Vite**：界面组件化，开发热更新，生产构建输出到 `ui-dist`。
- **安全隔离**：新增 `preload.js`，开启 `contextIsolation`，渲染进程不再直接 `require('electron')` / `fs`。

### ✨ 界面精修（向日葵工坊）

- 青绿主色 + 琥珀点缀、细颗粒纹理、面板悬停与入场动效。
- 工具栏分组、空状态引导、可拖拽分栏、圆角卡片与毛玻璃弹窗。
- 搜索框图标、同步配置双栏布局、帮助文案与更新横幅统一视觉语言。

### 🧰 体验与逻辑

- 仓库列表模糊搜索（Fuse.js）与拖拽排序（SortableJS）。
- Toast（Notyf）；更新日志 Markdown（marked + DOMPurify）。
- `Ctrl+Enter` 提交、`Esc` 关窗；提交按钮防重复点击。
- 强制拉取改为 `fetch + reset --hard`，提示更明确。

### 📝 说明

- 版本号 **1.2.0**。
- 开发：`npm run dev`；打包：`npm run build` / `npm run publish`。
