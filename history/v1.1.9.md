## 🌻 向日葵Git仓库管理 v1.1.9

### 🐛 提交统计修复

- **文件类型统计完整**：修正误用不存在的 `status.untracked`，按文件状态正确统计修改 / 新增 / 删除 / 重命名。
- **行数统计完整**：改用 `git diff --cached --numstat`，新增与删除文件的行数一并计入提交信息。
- **默认提交信息**：选中仓库或刷新变更后，默认文案自动带上「修改 / 新增 / 删除」等文件数总和预览。

### ⚙️ 更新代理端口

- **平台配置新增「应用更新代理端口」**：填写本地 HTTP 代理端口（如 Clash / V2Ray 的 `7890`）。
- **失败自动重试**：检查更新或下载更新直连失败时，自动改用 `127.0.0.1:端口` 再试一次。

### 🔗 同步与其它

- **暂存更完整**：统一使用 `git add -A`，删除文件也会进入暂存与统计。
- **同步逻辑**：从仓无实质变更时跳过空提交；路径无效给出明确错误；同远程仍走 pull。
- **克隆修复**：修正 `git-clone` 工作目录未定义导致失败的问题。
- **清理冗余**：移除无效的更新「代理拦截器」注释与重复统计逻辑。
