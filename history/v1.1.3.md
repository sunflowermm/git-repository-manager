## 🌻 向日葵Git仓库管理 v1.1.3

### 🔧 优化

- **并发操作体验**：多仓库同时提交/推送/同步时，选中态和日志输出互不影响，不会出现“正在操作的仓库被自动切回去”或日志串仓库的问题
- **日志可读性**：统一为所有 Git 操作按钮补充带仓库前缀的日志（如 `[repo-name] 提交成功`），便于快速定位问题

### 🧱 底层完善

- **Git 环境隔离**：不再通过修改全局 `process.env` 设置代理/SSH，每次 git 命令独立注入环境变量，避免并发操作相互污染
- **配置收敛**：删除冗余的环境切换辅助函数，统一通过 `runGitCommand + buildGitEnvOverrides` 执行带配置的 git 命令
- **渲染层简化**：移除依赖“当前选中仓库”的旧配置读取函数，改为按仓库快照获取平台配置，减少状态竞争

### 📝 说明

- 版本号升级为 1.1.3
- 本版本聚焦并发安全和日志可观测性，推荐所有用户升级
